# Local game-menu asset extraction

    dotnet run --project tests/better_kbm/game_menu_assets/GameMenuAssetsTests.csproj -c Release

Runs on .NET 8 or newer without Windows/WPF. All textures, glyphs, TPF records
and DCX archives are generated by the test; no game files are redistributed.
Checks PS4 BC1/BC7 untile/decode, PNG creation, DefineFont3 conversion, source
folder validation, cache reuse/repair and cancellation/staging cleanup.
User settings, save files and the real game directory are never accessed.
